# Rust stdout transport

Sindarin `print` and `println` output generated by the Rust target uses the
platform C `stdout` stream whenever a module contains built-in output. This is
a Rust-private ABI adaptation: the C target, shared model, language, and source
semantics are unchanged.

Using the same `FILE *` as generated and native C preserves the tagged target's
observable buffering boundaries. In particular, redirected stdout remains
buffered until the C runtime flushes it, terminal stdout retains the runtime's
terminal policy, an explicit native `fflush(stdout)` sees preceding Sindarin
output, and native `printf`/`puts` append to the same ordered stream. Rust does
not flush before a native call. The native bridge's compatibility flush is
also omitted when this shared transport is active, because an extra flush after
every native call is not present in tagged C.

Formatting remains Rust-private and byte strings retain their exact bytes. A
formatted scalar call is rendered before one `fwrite`; byte-string and
character lines append their newline before one `fwrite`. The C runtime owns
stream locking, buffering, newline translation, and process-exit flushing.
Compiler-private symbols for the stream, `fwrite`, and writer helpers are
allocated through the existing collision-free name allocator.

The regression `tests/rgen/assert_stdout_flush_order.sn` is byte-identical to
the unchanged tagged `tests/integration/test_assert.sn`. Its merged-stream
oracle requires the failed assertion on stderr before the previously buffered
stdout. `tests/rgen/output_helper_name_collisions.sn` covers source identifiers
that collide with every preferred helper name.

Linux differential controls additionally cover pipe and PTY output, successful
and nonzero process termination, an assert-present/assert-absent pair, 10,000
successive writes, native `printf`/`puts`/`fflush` plus stderr interleaving, and
a joined native pthread writer at `-O0`, `-O1`, and `-O2`. Source-level thread
syntax and the `exit()` built-in are still rejected by the Rust validator, so
those language families are not claimed by this transport slice. Windows and
macOS require their platform CI checks; the pending Windows text-output work
overlaps this transport and must retain this single-stream contract rather than
adding per-call flushes.
